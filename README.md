# HONEYCOMB-01

A pixel-art GameMaker game for **NASA Space Apps 2026**, challenge: *Build a Junior Astronaut Mission Trainer*.

## Story
Francis, a beekeeper, is recruited for a Mars botanical expedition. On Mars he finds the Tall Harvest dome has plenty of flowers but almost no fruit. By investigating clues, he discovers that artificial greenhouse lights are keeping the night-active native pollinators away, and restores their dark hours so they can return.

## What the player trains
- Spacecraft pre-flight system checks (communications, crew safety, life support, power, navigation, scientific payload)
- Atmospheric entry: heat-shield tilt control
- Parachute timing
- Retro-thruster landing
- Scientific method on Mars: collecting field notes, choosing a hypothesis, and testing it with a lighting puzzle

## Controls
- Move: WASD or arrow keys
- Interact: E
- Advance dialogue: Space, Enter or mouse click
- Menus and puzzles: Up/Down, Left/Right, Enter

## Play it
Download the latest build from the **Releases** page (right side of this repo), unzip it, and run the .exe.

## Open the source
Install GameMaker, then open the `.yyp` file in this repo.
